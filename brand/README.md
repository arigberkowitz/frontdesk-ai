# Brand assets

`frontdesk-logo-120.png` — the 120×120 logo submitted to Google Cloud for the OAuth
consent screen (Branding page). Google requires a square PNG at this size, and it is
what callers' browsers show on the "FrontDesk AI wants access to your Google Account"
screen when a business connects its calendar.

Kept in the repo because it was generated once, by hand, and the OAuth branding has to
be re-submitted with the identical asset if it is ever changed or re-verified.
